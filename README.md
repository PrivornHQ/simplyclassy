# SimplyClassy Launch

Here's the combined, final prompt for Lovable:

Build a modern, elegant e-commerce landing website called SimplyClassy.

Brand description: Simply Classy is your home for authentic wrist watches, Nike Mind001 sneakers, and long-lasting designer perfumes. We sell time, scent, and style — affordable luxury delivered nationwide in Ghana.

Color palette: Ash grey, white, and coffee brown — clean, minimal, premium aesthetic.

Structure & features:

Sticky navbar with anchor links to each category (Perfumes, Sneakers, Watches), smooth scroll on click

Hero section with brand name, tagline, and a strong CTA button

Trust badges row: "Authentic Products", "Nationwide Delivery", "Secure Payment"

Products displayed in 3 clear categories: Perfumes, Sneakers, Watches — each with its own grid section (placeholder image, name, price in GHS ₵, "New Arrival" / "Best Seller" badge option)

Simple filter/sort within each category (price low-high, newest)

About section highlighting affordable luxury and nationwide delivery in Ghana

Customer testimonials/reviews section

Instagram feed/gallery placeholder section

Simple WhatsApp broadcast/newsletter signup form (capture name + WhatsApp number)

Sticky/floating WhatsApp button on all pages linking to https://wa.me/233243954370 (pre-filled message: "Hi, I'm interested in a product from SimplyClassy")

Footer with contact info, WhatsApp link, and social links placeholder

Fully responsive, mobile-first, optimized for fast loading on slower mobile data

Images: Use clean placeholder images/blocks for all products, hero, and Instagram gallery — structured so I can easily swap them for real photos in the code afterward (clear, consistently named placeholder file paths or components).

SEO requirements:

Page title: "SimplyClassy | Authentic Watches, Sneakers & Perfumes in Ghana"

Meta description summarizing the brand description above

Semantic HTML (proper h1/h2 structure, alt text on all product images)

Open Graph tags (og:title, og:description, og:image)

Structured data (schema.org) for Organization and Product types

AEO (AI answer engine optimization):

FAQ section answering: "What does SimplyClassy sell?", "Does SimplyClassy deliver nationwide in Ghana?", "How do I contact SimplyClassy?" — clear, direct language

Brand name "SimplyClassy" and core offerings appear clearly in headings and body text, not just images

Paste this into Lovable as-is.
